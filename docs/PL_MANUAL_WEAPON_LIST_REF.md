## RE 関連 — 備考欄の読み方

**備考** の「適合弾薬」= CBE `ammo_indices` 4 スロット（cat18）候補。  
「装着銃剣」「装着三脚」= **付属品** — CBE では cat24 / +0x34 / u16[26] 経路（[PL_CBE_UI_TABLE_RE.md](./PL_CBE_UI_TABLE_RE.md)）。

例（本資料）:

```
適合弾薬3006-5, M9A1 RfG, Mk2 GPA, 装着銃剣M1905Byt
```

→ 主弾 + 擲弾2行 + 銃剣（4スロット相当）の**人間可読表記**。

## アメリカ — 本資料 vs CBE（要点）

### ライフルグレネード（M9A1 RfG / Mk2 GPA）

| 武器 | 本資料 適合弾薬/付属 | CBE 整合 |
|------|-------------------|----------|
| M1903A1 | 3006-5, **M9A1 RfG**, **Mk2 GPA**, M1905 Byt | 245/244 スロット — 整合 |
| M1 Rifle | 3006-8, M9A1 RfG, Mk2 GPA, M1905 Byt | 同上 |
| M1/M1A1/M2 Cbn | 30Cbn-15/30, **M9A1 RfG**, M4 Byt | 整合 |
| M1C/M1D | 3006-8 のみ | 擲弾なし — 整合 |

**M9A1 RfG はライフル/カービン系のみ**。M9 RL とは無関係（本資料でも分離）。

### ロケットランチャー

| 武器 | 本資料 | CBE |
|------|--------|-----|
| M1 RL | **M6A1 HR** | 242/243 行。M1 RL スロットは主に 243 M6A5 HR |
| M1A1 RL | **M6A1 HR** | 同上 |
| **M9 RL** | **M6A1 HR, M6A3 HR** | 243 **M6A5 HR**（**M6A3 名称なし**）。244 M9A1 RfG は CBE 異常 |

→ 本資料の **M6A3** = 史実表記。PL バイナリ上は **M6A5 HR(243)** が対応行。M6A1 HR(242) も存在。

### 機関銃 + 弾薬箱 + 三脚

| 武器 | 本資料 | CBE +0x34 (u16[26]) |
|------|--------|---------------------|
| M1919A6/A4/A7A1 | 3006-200/250, **M1 Ammobox**, M1917/M2 Tripod | → 35 M2HB Ammobox ※名称ゆれ要確認 |
| M2 HB | 50M2-110, **M2 Ammobox**, **M3 Tripod** | → 36 **M3 Binocular**（本資料と不一致 — CBE 要 RE） |
| M1 Ammobox | 軽機・重機用 | 内包 3006-250, 50M2-110 |
| M2HB Ammobox | M2 HB 用 | 内包 M6A1 HR |

本資料は **弾薬箱・三脚を「適合弾薬/備考」に同居** — CBE では主弾 4 スロットと **u16[26] (+0x34)** に分離。

## 使い方（ST プロジェクト）

1. **CBE `ammo_indices` が空/欠落**のとき、本資料で「あるべき組み合わせ」を人手確認
2. **備考の「装着〜」** → cat24 / +0x34 RE の期待値
3. **弾薬表の「装填可能武器」** → 逆引きテストケース（3603, 3605, 3608）
4. **本資料と CBE が食い違う場合** — CBE+RE を正本とし、差分を本 doc に追記
