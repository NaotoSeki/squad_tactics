# Art Bible: Squad Tactics WW2 Military Projection (v3.0)

本書は兵士・車両・環境アセットを同じ画面へ統合するための描画正本です。
投影・光・回転規則は`docs/MAP_SYSTEM_HANDOFF.md`および現行HexKitレンダー設定と一致させます。

## 1. カメラと投影（最重要）

- **正本**: 仰角**55°**のOrthographicカメラによる軍用正投影（military projection）。
- **平面補正**: `pixel_aspect_x = 1 / sin(55°)`。この補正で地面の平面図を無歪に保ち、
  正六角形・道路幅・実世界オフセットをそのまま合成できる。垂直要素だけが画面縦方向へせん断される。
- **環境タイル基準**: hex外接半径9m、実世界カバー幅20.25m、288×384px、
  アンカー(144, 234.5)、画面上が北。
- **禁止**: 旧アイソメトリック規格、真上視点、透視投影、アセットごとの独自カメラ。

## 2. スタイルと材質

- **目標**: Panzer Strike / Sudden Strike系の、自然主義的で高密度なWW2戦場表現。
  泥、すす、風化、砲撃痕、草木、生活痕を小さなスケールでも読める密度で重ねる。
- **材質**: 写実寄りのPBRを基礎に、roughness・bump・grimeを抑制的に使う。
  プラスチック光沢、過剰なコントラスト、均一な手続きノイズ、反復の強い接写テクスチャは避ける。
- **禁止する画風**: 太いアウトライン、ピクセルアート、Toon/Painterlyを主役にした
  カートゥーン表現。可読性は輪郭線ではなく、明度差・形状・配置密度で確保する。

## 3. ライティングと色

- **光源方向**: 太陽は**南西上空**から固定。影は**画面の東（右）**へ落ちる。
  環境・兵士・車両・AI補助素材を含め、別方向の焼き込み影を混在させない。
- **現行基準値**: 太陽仰角62°、energy 4.2、環境光0.58、High Contrast。
- **基調色**: 彩度を抑えたfield gray、olive drab、mud brown、すすけた煉瓦色、
  枯れ草と湿った緑。アクセントは砲火の鈍い橙と冷たい環境青に限定する。

## 4. 生成・回転規則

- **共通リグ**: 新規アセットは現行HexKitと同じ55°カメラ・pixel-aspect補正・南西光で焼く。
- **回転は焼き込み**: 必要方向をBlender側で個別レンダーし、各PNGに正しい固定影を持たせる。
- **実行時回転は禁止**: Phaserの`setAngle`等でPNGを回してはならない。影方向と軍用投影が破綻する。
- **兵士・車両**: 方向別アニメーションは3Dリグから焼き、環境と同じ投影・光源・実寸感を使う。
- **環境・ウワモノ**: Blenderプリレンダーを正本とする。AI生成を補助に使う場合も、
  55°軍用正投影・南西光・東向きの影・自然主義的材質を参照画像やブロックアウトで固定する。

## 5. 受け入れ基準

- 地面の正六角形が無歪で、既存タイルのアンカーと一致する。
- 影が東へ落ち、別方向の影や画像回転痕がない。
- 同縮尺で既存建物・兵士・車両と並べても、材質密度と実寸感が破綻しない。
- 透過PNGはRGBAで、切れ・空alpha・不要な背景色を含まない。
