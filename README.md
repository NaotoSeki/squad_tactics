# SQUAD TACTICS

第二次世界大戦を題材にした、リアルタイム＋一時停止（RTwP）専用の分隊戦術ゲームです。ヘックス戦場で兵士へ大まかな命令を与え、個々の能力・スキル・現場判断がその実行を変化させます。

## 現行ゲームループ

1. 候補カードから分隊を編成する。
2. 戦場へ兵士・装備・支援カードを投入する。
3. リアルタイムで状況を観察し、必要な時だけ一時停止して命令する。
4. セクター制圧後、戦果・損耗・成長を確認して次へ進む。

## 戦闘操作

- 味方を左クリック: 個人命令メニュー（移動・制圧・強襲）
- 左ドラッグ: 複数選択。対象をドラッグして各兵へ割り当て
- 右クリック / Esc: 選択中の命令を取り消す
- Space: 一時停止／再開
- 1 / 2 / 3: 速度 1x / 2x / 4x
- F: 分隊の集中射撃
- A: 一帯への制圧射撃
- C: 分隊へ遮蔽命令

射撃、再装填、姿勢、走行、匍匐、投擲、白兵はRTwPシムが状況と命令から連続的に解決します。

## 技術構成

- `logic_battle_rtwp.js`: 本編とRTwPシムの接続、入力、イベント、状態同期
- `sim_core.js`: 固定100ms tickの戦闘正本
- `sim_policy.js`: 個人トレイトと自己判断
- `sim_orders.js`: 命令伝達遅延
- `sim_actions.js`: 画面とホットキーが共有する行動カタログ
- `data.js`: 武器、能力、スキル、RTwP効果、調整値の正本

ブラウザで `index.html` を開いて実行します。開発時の構造と監査結果は `ARCHITECTURE.md` と `docs/RTWP_CONNECTION_AUDIT.md` を参照してください。
